# فيديو ٥ — "أحمر ولا أبيض؟" (الاستعجال التعليمي)

**المنتج:** السيروم | **المدة:** ٢٠–٢٥ ثانية | **الستايل:** تعليمي سريع — جرافيكس + لقطات جلد، إيقاع سريع

## السكربت الصوتي كامل

> "معلومة ما حد يقولها: التشققات الحمراء والبنفسجية لسا فيها دم وجذور حية — يعني قابلة للعلاج بسرعة. إذا استنيتي وصارت بيضاء فضية؟ الموضوع يصير أبطأ وأصعب بكثير. فترة اللون هي الذهبية — وسيروم سيلورا مصمم بالضبط لهذي المرحلة: يوصل للطبقة المصابة ويحفز تجديدها قبل ما يقفل الجرح. لا تستنين الولادة تخلص والتشقق يشيخ. ابدئي اليوم — دفع عند الاستلام."

| ٢–٩ ث | الشرح | بانل متقسم: يمين تشققات حمراء/بنفسجية (طازجة)، يسار بيضاء فضية (قديمة). نص يطلع فوق كل وحدة: **"قابلة للعلاج بسرعة"** / **"أصعب بكثير"** |
| ٩–١٦ ث | العد التنازلي | جرافيك خط زمني: تشقق أحمر يتلاشى لأبيض عبر تقويم يتقلب — نص: **"كل أسبوع تأخير = علاج أصعب"** |
| ١٦–٢٥ ث | الحل | لقطة السيروم يتغلغل بالجلد الملون + **"مصمم لهذي المرحلة بالضبط"** + CTA عاجل |

## نصوص الشاشة

- `⏳ إذا تشققاتك لسا حمراء — عندك نافذة ما تدوم`
- `أحمر/بنفسجي = جذور حية = علاج سريع`
- `أبيض/فضي = قديم = أصعب`
- `كل أسبوع تأخير = علاج أصعب`
- `ابدئي اليوم — دفع عند الاستلام`
